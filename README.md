# PRISMA Renting — Archic concept

High-fidelity commercial prototype for PRISMA Renting.

## Stack
- Next.js 16 Active LTS
- React 19.2
- TypeScript
- ESLint Core Web Vitals + TypeScript rules

## Scope in this first build
- Premium, conversion-led homepage
- Renting finder for Particular / Autónomo / Empresa
- Real PRISMA offer data seeded from the current public catalogue
- Filterable offer catalogue
- Vehicle detail pages
- Guided lead qualification flow
- PRISMA Control commercial dashboard concept
- Responsive design

## Run
```bash
npm install
npm run dev
```

## Product direction
This prototype intentionally preserves PRISMA's existing SEO surface conceptually while moving catalogue, offer data and lead capture toward a structured data model that can later connect to Supabase/Postgres or an existing feed.
